GlucoHabit 血糖記録

利用規約

制定：2026年8月17日  ／  運営者：IronDesign
本利用規約（以下「本規約」といいます。）は、IronDesign （以下「運営者」といいます。）が提供するスマートフォン向けアプリ 「GlucoHabit」（以下「本アプリ」といいます。）およびこれに関連して 運営者が提供する一切のサービス（以下「本サービス」といいます。）の 利用条件を定めるものです。

本アプリを利用するすべての方（以下「ユーザー」といいます。）は、 本規約に従って本サービスを利用するものとします。 ユーザーは、本アプリをダウンロード、インストール、閲覧または 利用した時点で、本規約に同意したものとみなされます。

第1条（適用）

  1. 本規約は、ユーザーと運営者との間の本サービスの利用に関わる一切の関係に適用されるものとします。
  2. 運営者は、本サービスに関し、本規約のほか、ご利用上のルール、ガイドライン、説明文、注意事項等（以下「個別規定」といいます。）を定めることがあります。
  3. 個別規定はその名称のいかんを問わず、本規約の一部を構成するものとします。
  4. 本規約の定めと個別規定の定めが矛盾する場合には、個別規定に別段の定めがない限り、個別規定が優先して適用されるものとします。

第2条（本サービスの内容）

  1. 本サービスは、ユーザーが血糖値、食事、運動、水分摂取、体調、メモその他健康管理に関連する情報を記録、閲覧、整理および振り返ることを支援することを目的とするサービスです。
  2. 本サービスは、一般的な健康管理および自己記録の補助を目的として提供されるものであり、医療行為、診断、治療、看護指示またはこれらに類する行為を行うものではありません。
  3. 本アプリ上で表示される数値、記録、グラフ、分析結果、通知、提案その他の情報は参考情報にすぎず、医師その他医療専門職による判断に代替するものではありません。

第3条（利用条件および匿名識別情報）

  1. ユーザーは、本規約に同意の上、本サービスを利用するものとします。
  2. 本サービスでは、原則として、ユーザーが氏名、メールアドレス、パスワード等を入力して一般的な会員登録を行う必要はありません。
  3. 本サービスの提供、データ管理、クラウド同期その他必要な機能のため、システム上、ユーザーを識別するための匿名の識別情報が自動的に生成または付与される場合があります。
  4. ユーザーは、自己の責任において、本サービスを利用する端末および端末へのアクセス手段を適切に管理するものとします。

第4条（端末およびデータの管理）

  1. ユーザーは、自己の責任において、本サービスを利用する端末および当該端末に保存された情報を適切に管理・保管するものとします。
  2. 端末の紛失、第三者による利用、端末の初期化、アプリの削除その他の事情によりデータが失われる場合があります。
  3. 端末または本サービスの管理不十分、使用上の過誤、第三者による利用等によって生じた損害について、運営者は、運営者に故意または重過失がある場合を除き、責任を負いません。

第5条（記録情報および入力内容）

  1. ユーザーは、本アプリに入力、記録または保存する血糖値、食事、運動、水分摂取、体調、メモその他一切の情報について、自らの責任において管理するものとします。
  2. ユーザーは、本サービスに入力する情報が、可能な限り正確かつ最新の内容となるよう努めるものとします。
  3. 運営者は、ユーザーが入力した情報の正確性、完全性、有用性または最新性を保証するものではありません。
  4. 本サービスに保存された記録は、端末の故障、OS更新、通信障害、クラウド障害、外部サービス障害、誤操作その他の事情により消失または毀損する可能性があります。ユーザーは必要に応じて自己の責任でバックアップその他の対応を行うものとします。

第6条（医療上の免責）

  1. 本サービスは医療機器ではなく、医師法その他の法令上の医療行為を提供するものではありません。
  2. 本サービスに表示される記録、分析、通知、推移、傾向表示、コメントその他の情報は参考情報であり、医療上の最終判断は、必要に応じて医師その他適切な医療専門家に相談のうえ、ユーザー自身の責任で行うものとします。
  3. ユーザーは、本サービスの情報のみに依拠して、受診、治療その他健康状態に関する重要な判断を行うべきではありません。
  4. 緊急の医療対応を要する可能性がある場合、ユーザーは直ちに医療機関または救急サービスに連絡するものとし、運営者はこれに代わる対応を行う義務を負いません。

第7条（個人情報および健康関連情報の取扱い）

  1. 運営者は、本サービスの提供にあたり取得するユーザーの利用情報および健康関連情報を、別途定める「GlucoHabit プライバシーポリシー」に従って取り扱うものとします。
  2. 本サービスでは、血糖値、食事記録、運動記録、水分摂取記録、体調情報その他の健康関連情報を取得、保存、利用または処理する場合があります。
  3. クラウド同期、バックアップ、匿名認証、サブスクリプション管理、問い合わせ対応その他の機能のため、情報が運営者または運営者が利用する外部サービス提供事業者のサーバーに送信・保存される場合があります。
  4. 運営者は、法令で認められる範囲において、統計情報その他個人を特定できない形に加工した情報を、本サービスの改善、分析、開発その他の目的で利用することがあります。

サブスクリプションは、現在の期間終了の24時間以上前に自動更新を停止しない限り、自動的に更新されます。

サブスクリプションの管理および解約は、Apple ID の App Store アカウント設定から行うことができます。
